# tools-by-storitellah

| Tool | What it is |
| --- | --- |
| [Filmcase](Filmcase/) | A vintage film camera for iPhone. Nine film stocks, developed live in the viewfinder. SwiftUI + AVFoundation + Core Image, on-device only. |
| [Keepframe](Keepframe/) | An instant-film print studio in a single HTML file. Turns any photo (JPG, HEIC, TIFF, RAW…) into mini, square or wide prints with frames, film looks and handwritten captions, then prints true-size sheets ready to cut. |
