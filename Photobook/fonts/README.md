# Fonts

The default theme looks for these files here:

```
BobbyJonesSoft.otf
TTNorms-Light.otf
TTNorms-Regular.otf
TTNorms-Italic.otf
TTNorms-Bold.otf
TTNorms-Black.otf
```

They are the project's licensed typefaces (from the *This Is Where We're From*
repository) and are not committed to this repository. Font files in this folder
are git-ignored. Check that the licence allows web use before you deploy them.

If the files are missing, the tool uses Lilita One and Outfit instead. You can
also add the fonts inside the tool: **Book & theme → Fonts → Add font files**.
